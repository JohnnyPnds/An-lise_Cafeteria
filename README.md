# An-lise_Cafeteria
Projeto de análise de dados voltado à tomada de decisão estratégica em uma rede de cafeterias. A partir de uma base bruta, foi realizado o pipeline completo de limpeza, estruturação e visualização de dados em Python, identificando gargalos operacionais e 3 alavancas práticas para aumentar a rentabilidade do negócio.
